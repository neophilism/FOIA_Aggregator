About the project

One search across federal records that agencies have already released.

FOIA Aggregator discovers official agency reading rooms and disclosure libraries, archives released records, preserves source provenance, extracts native document text, and applies OCR to scanned records so material that is public but fragmented across government websites can be searched from one place.

What it does

The platform is focused on records that government agencies have already made public through FOIA reading rooms, electronic libraries, proactive-disclosure pages, and comparable official repositories. It does not file requests on a user's behalf. Instead, it makes already-released material easier to discover across agency boundaries.

Coverage

The source-discovery system uses FOIA.gov metadata as its federal backbone, supplemented by verified source corrections and curated coverage where official metadata is incomplete. The current database contains {{ "{:,}".format(stats.agencies) }} agencies, {{ "{:,}".format(stats.offices) }} offices/components, and {{ "{:,}".format(stats.active_sources) }} active official publication sources.

Search and preservation

Every archived file retains its government source URL and archive metadata. Born-digital PDFs, DOCX files, and text-like formats can be indexed directly. Image-only PDF pages and common image formats can be OCRed with bounded resource limits. Archived files are content-addressed by SHA-256 when stored in Backblaze B2, reducing duplicate storage while preserving integrity metadata.

Design principles

  • Official source provenance remains visible.
  • The archived source file remains authoritative; extracted/OCR text is a search aid.
  • Crawling is bounded by source, depth, page count, file size, and rate limits.
  • Search spans agencies by default rather than forcing users to know where a record lives first.
